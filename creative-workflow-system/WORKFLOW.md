# WORKFLOW.md — 制作手順・チェックリスト

ここは記事でいう「Skills（再利用できる手順）」と「Verification Loop（検証）」の
簡略版です。毎回この手順とチェックリストに沿って作れば、品質が安定し、確認漏れが減ります。

手順そのものを見直したら、このファイルを直接アップデートしてください。
（＝これが「スキルの改善」です。特別な仕組みは不要で、このファイルを書き換えるだけでOK）

---

## 共通の流れ（どの制作物にも共通）

1. **企画**：`MASTER.md` の世界観・`CHARACTER_BIBLE.md` を確認してネタを決める
2. **制作**：`STYLE_GUIDE.md` を見ながら作る
3. **確認（検証）**：下記チェックリストで自分の目でチェックする
4. **公開・保存**
5. **記録**：`LOG.md` に結果を一行残す

---

## A. Instagram投稿

**企画**
- [ ] `MASTER.md` のターゲット像・トーンに合っているか
- [ ] 登場キャラの設定を `CHARACTER_BIBLE.md` で確認したか

**制作**
- [ ] `STYLE_GUIDE.md` のカラーパレット・フォント・レイアウトに沿っている
- [ ] キャラの見た目の外せない特徴が反映されている
- [ ] キャラの口調がセリフに反映されている

**確認（投稿前チェック）**
- [ ] NG表現・避ける表現に触れていないか（`MASTER.md` `CHARACTER_BIBLE.md`）
- [ ] 誤字脱字がないか
- [ ] スマホの小さい画面で見ても文字が読めるか
- [ ] ブランドとして「これは出して恥ずかしくない」と思えるか

**公開後**
- [ ] `LOG.md` に投稿日・内容・気づきを記録

---

## B. 絵本

**企画**
- [ ] 伝えたいテーマ・オチを一文で言えるか
- [ ] ページ構成（起承転結）をざっくりメモしたか

**制作**
- [ ] `STYLE_GUIDE.md` の絵本ルール（文字量・ふりがな等）に沿っている
- [ ] キャラの性格・口調が一貫している

**確認（検証）**
- [ ] 通してページをめくって読み、話がつながるか確認した
- [ ] 対象年齢の子どもが読める言葉遣いか
- [ ] NG表現に触れていないか

**公開後**
- [ ] `LOG.md` に記録（制作期間・難しかった点も書く）

---

## C. LINEスタンプ

**企画**
- [ ] どんなシーンで使ってもらいたいスタンプセットか決めた
- [ ] 表情・ポーズのバリエーションリストを `STYLE_GUIDE.md` の基本セットと照らして決めた

**制作**
- [ ] サイズ・余白・文字入れルールを守っている
- [ ] キャラの外せない特徴が小さいサイズでも分かる

**確認（検証）**
- [ ] 一覧表示（40個並び）で見ても違うキャラに見えないか
- [ ] 実際のトーク画面サイズで見て文字が読めるか
- [ ] LINE Creators Marketの審査ガイドラインに沿っているか

**公開後**
- [ ] `LOG.md` に記録（審査結果・売れ行き・気づき）

## 手順の見直しルール

`LOG.md` を振り返って、同じ手間・同じミスが3回以上出てきたら、
このチェックリストに項目を1つ追加する。これが手作業版の「スキル自動生成」です。
