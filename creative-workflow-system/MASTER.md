# MASTER.md — 全体方針・世界観・制作ルール

このフォルダは、あなたの創作活動（Instagram投稿・絵本・LINEスタンプなど）を
「毎回ゼロから思い出す」のではなく「積み上げていく」ための運用フォルダです。
Googleドライブに置いて、制作のたびに関連ファイルを開いて参照・更新してください。

---

## 0. このフォルダの考え方（かんたん版）

参考にした記事（Fable 5）では「STATE.md／Memory／Skills／Verification Loop」という
仕組みが出てきますが、個人の創作activityではここまでは不要です。以下のように置き換えています。

| 記事の概念 | このフォルダでの役割 | 使うファイル |
|---|---|---|
| STATE.md（今の状況を記録） | 「今どの作業をしていて、どこまで進んだか」を書く | `LOG.md` |
| Memory（記憶・過去の学び） | 「一度決めた設定・世界観を忘れない」ための保管庫 | `CHARACTER_BIBLE.md` `STYLE_GUIDE.md` |
| Skills（再利用できる手順） | 「毎回同じ手順で作れば失敗しにくい」チェックリスト | `WORKFLOW.md` |
| Verification Loop（検証） | 投稿・出版前に自分の目で確認する最終チェック | `WORKFLOW.md` 内の確認欄 |
| 一時メモ（Working Memory） | まだ整理していない思いつき置き場 | `INBOX.md` |

むずかしいシステムを作る必要はありません。
**「書く→溜める→振り返る→次に活かす」を繰り返すだけ**で、記事にある自己改善の考え方は再現できます。

## 5. ファイル構成と役割

| ファイル | 役割 | 更新タイミング |
|---|---|---|
| `MASTER.md` | 全体方針・世界観（このファイル） | 方針が変わった時のみ |
| `CHARACTER_INDEX.md` | キャラクター一覧 | 新キャラ登場時 |
| `CHARACTER_BIBLE.md` | キャラごとの詳細設定 | 設定を決めた/直した時 |
| `STYLE_GUIDE.md` | 絵柄・色・文章トーン | スタイルを決めた/直した時 |
| `WORKFLOW.md` | 制作手順・チェックリスト | 手順を改善した時 |
| `INBOX.md` | 未整理メモ置き場 | 思いついたら随時 |
| `LOG.md` | 作業履歴・振り返り | 制作のたびに |

## 6. 運用ルール

1. 何か作る前に `WORKFLOW.md` の該当手順を開く。
2. 作りながら思いついたことは `INBOX.md` に放り込む（後で整理でOK）。
3. 作り終えたら `LOG.md` に一行でも記録する。
4. 週1回くらい `INBOX.md` を見返し、使えるものは `CHARACTER_BIBLE.md` / `STYLE_GUIDE.md` / `WORKFLOW.md` に移して `INBOX.md` から消す。
5. `LOG.md` に同じ失敗・同じ改善点が3回出てきたら、それは「ルール化すべきこと」。`WORKFLOW.md` か `MASTER.md` に反映する。

> 6番が、記事でいう「Skills自動生成（繰り返しパターンをスキル化する）」の手作業版です。
